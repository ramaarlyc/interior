# LUKMAN INTERIOR — Sistem Manajemen RAB & AHSP Interior

Aplikasi manajemen Rencana Anggaran Biaya (RAB) dan Analisis Harga Satuan Pekerjaan (AHSP) terintegrasi khusus untuk industri pengerjaan interior, kitchen set, custom furniture, dan renovasi ruangan. Bekerja 100% offline langsung dari peramban web tanpa memerlukan database server tambahan.

## Fitur Utama

- **18 Preset Interior Siap Pakai**:
  - Kitchen Set Bawah & Atas (Multipleks 18mm + HPL Taco + Edging PVC).
  - Table Top Granit / Solid Surface (include beading & coak).
  - Backdrop TV Minimalis (Kisi-kisi WPC, Ambalan Gantung, Indirect LED Strip 12V).
  - Lemari Pakaian / Wardrobe Full Plafon & Semi-Walk-in.
  - Dipan Tempat Tidur Minimalis + Headboard Busa Lapis Kain.
  - Meja Kerja / Belajar Custom, Partisi Ruangan 2 Muka, Meja Rias + Cermin Bevel.
  - Plafon Drop Ceiling Gypsum + Rangka Hollow Galvanis, Flooring Vinyl/SPC, Pengecatan Interior.
- **Rincian Komponen AHSP Lengkap & Otomatis**:
  - Setiap pekerjaan langsung memuat koefisien riil material, tukang kayu, pekerja, mandor, dan peralatan penunjang.
  - Tombol **⚡ Muat Template AHSP Lukman** untuk memuat ulang formula standar industri.
  - Penyesuaian harga satuan otomatis mengkalibrasi harga material atau dapat disesuaikan manual.
- **Pencetakan & Ekspor Dokumen Profesional**:
  - Penawaran harga ringkas untuk customer.
  - RAB Detail transparan (volume, koefisien, dan material).
  - Rekapitulasi kebutuhan total material dan tenaga kerja.
  - Ekspor data proyek & backup database JSON lokal.
- **Database Wilayah Indonesia Tertanam (Full Offline)**:
  - 38 provinsi, 514 kabupaten/kota, 7.285 kecamatan, 83.762 desa/kelurahan tertanam langsung dalam aplikasi.

## Cara Menggunakan

1. Buka file `index.html` atau `RAB.html` langsung menggunakan browser apa pun (Google Chrome, Safari, Edge, Firefox).
2. Buat proyek baru atau pilih proyek yang sudah ada.
3. Masuk ke halaman RAB, klik salah satu tombol preset interior untuk menambahkan pekerjaan secara instan.
4. Klik tombol **AHSP** pada baris pekerjaan untuk melihat, mengedit rincian bahan material, atau menyesuaikan koefisien tukang.
5. Klik **Cetak PDF Penawaran** untuk mengunduh dokumen penawaran rapi siap kirim ke klien.
